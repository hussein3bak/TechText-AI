Pipeline Pipeline Stages

  1. Data Collection: Automated Wikipedia Tech & AI articles scraping using polite rate limiting.
  2. NLP Cleaning: HTML stripping, emoji removal, noise symbol cleanup, Unicode normalization, whitespace standardization.
  3. Tokenization: Character-level and BPE vocabulary tokenizers with fast serialization to binary arrays.
  4. PyTorch GPT: Causal Multi-Head Self-Attention, Positional Embeddings, GELU MLP blocks, Pre-LayerNorm.
  5. Inference API: FastAPI REST endpoints with temperature and top-k nucleus sampling.
  6. Persistence: SQLite database tracking prompt history and execution settings.
